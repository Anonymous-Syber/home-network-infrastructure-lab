# Project 01: Home Network Infrastructure Deployment
## Objective
Deploy and configure a small network using a GL.iNet GL-MT300N-V2 wireless mini router and Windows 11 Pro workstation.
## Hardware 
- GL.iNet GL-MT300N-V2
- Windows 11 Pro PC
- Intel Processor
- 64GB+ RAM
- 1TB SSD

## Network Architecture
- Wireless repeater Connection
- WISP routing mode
- Dedicated LAN subnet
- DHCP configuration
- DNS resolution
- Internet connectivity

## Testing
- ipconfig
- ping gateway
- ping 1.1.1.1
- nslookup google.com
- tracert google.com

## Results
Document actual configuration, screenshots, connectivity results, and troubleshooting.
